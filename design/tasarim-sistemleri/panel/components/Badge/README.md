# Badge

Kısa durum veya kategori etiketi; bir iki kelime.

| Ton | Örnek |
|---|---|
| `notr` | Taslak, Pasif |
| `marka` | Paket, Abonelik |
| `vurgu` | Yeni müşteri, Yeni |
| `basari` | Ödendi, Aktif |
| `uyari` | Az kaldı, Süresi doluyor |
| `hata` | Borçlu, Başarısız |
| `bilgi` | VIP, Not var |

- Randevu durumu için `Badge` değil `StatusBadge`.
