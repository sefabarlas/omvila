# AppointmentBlock

Takvimdeki randevu bloğu; zemin ve üst şerit durum rengini taşır.

- Üst satırda müşteri ve başlangıç saati, altında hizmet. "Onaylandı" dışındaki durumlar alt satırda adıyla yazılır.
- 45 dakikadan kısa bloklar kompakt görünür: tek satır, durum noktası adın önünde.
- İptal edilen randevu üstü çizili kalır ve saati boşaltır.
- Bekleyen randevular (Onay bekliyor, Kapora bekleniyor) kesik çizgili kenarla gösterilir: saat tutulmuş ama kesinleşmemiştir.
- Klavyeyle odaklanabilir; ekran okuyucu saat, müşteri, hizmet ve durumu okur.
