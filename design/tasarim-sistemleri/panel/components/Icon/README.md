# Icon

Lucide çizgi ikonları; 24px ızgara, 1.75 çizgi, rengi metinden alır.

- Boyutlar: 16px (küçük buton, rozet, giriş alanı), 18px (buton, menü), 20–24px (boş durum, kart başlığı).
- Tek başına anlam taşıyan ikon `IconButton` içinde ve `label` ile kullanılır.
- Pakette yalnızca kullanılan ikonlar vardır; yeni ikon Lucide'tan aynı adla eklenir.
