# Modal

Odaklı kısa görevler: randevu oluşturma, iptal onayı.

- Başlık görevi söyler ("Yeni randevu"); açıklama bağlamı verir (tarih, şube).
- Altbilgide sağda en fazla iki buton: `secondary` "Vazgeç" + `primary` eylem.
- Uzun formlar (hizmet tanımlama, personel çalışma saatleri) modal değil sayfa veya yan panel olur.
- `inline` yalnızca önizleme içindir; uygulamada modal sayfanın üstünde açılır.
