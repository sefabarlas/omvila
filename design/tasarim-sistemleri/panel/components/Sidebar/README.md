# Sidebar

Panelin ana menüsü; petrol zeminli, markanın panelde en görünür yüzeyi.

- Sıra: Özet, Takvim, Müşteriler · YÖNETİM: Hizmetler ve fiyatlar, Personel, Paketler, Kasa, Raporlar · Ayarlar.
- Şube seçici menünün üstünde; tek şubeli işletmede gizlenir.
- `count` yalnızca eylem bekleyen şeyler için (onay bekleyen randevu); mercan rozet.
- 1280px altında `collapsed` (64px); daraltılmış öğeler tooltip ile adını gösterir.
- Tüketici: `items` (gruplar ve öğeler), `active`, `branch`, `user`.
