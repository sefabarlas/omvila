# Logo

Kenar menüsü, giriş ekranı ve e-posta başlıklarında OMVILA amblemi ve kelime markası.

- `tone="ters"` yalnızca `sidebar-zemin` ve `zemin-marka` üzerinde; diğer zeminlerde `tone="acik"`.
- Daraltılmış menüde `showWordmark={false}`.
- Boyut 24–32px; daha küçükte Marka Sistemi'ndeki küçük amblem kullanılır.
