# Logo

Uygulama açılışı, giriş ekranı ve rezervasyon sayfası üst barında OMVILA amblemi ve kelime markası.

- `tone="ters"` yalnızca `zemin-marka` üzerinde.
- Salonun kendi rezervasyon sayfasında OMVILA logosu küçük kalır; ön planda salonun adı durur.

**Flutter:** `SvgPicture.asset('assets/omvila_logo_yatay.svg')` (flutter_svg); SVG'ler Marka Sistemi'ndeki Logolar grubundan.
