# TextField

Etiketi üstte, 48px yüksekliğinde giriş alanı.

- Etiket hep görünür; placeholder gerçek örnektir.
- Hata alanın altında, ne yapılacağını söyler.
- Klavye türü içerikle eşleşir (e-posta, sayı, telefon).

**Flutter:** `TextFormField` + tema `InputDecorationTheme`; etiket için alanın üstünde ayrı `Text(style: OmvilaYazi.etiketKucuk)`.
