# AppBar

Üst bar. Sekme kök ekranlarında büyük başlık (kaydırınca küçülür), detay ekranlarında geri oku ve ortalanmış başlık.

- Büyük başlığın altında bağlam: "Salı, 25 Kasım · 12 randevu".
- Sağda en fazla iki eylem.

**Flutter:** Kök: `SliverAppBar.large` / `CupertinoSliverNavigationBar`; detay: `AppBar(centerTitle: true)`.
