# BottomSheet

Ekranı terk etmeden kısa görev: randevu saatini değiştirme, filtre, paylaşım.

- Üstte tutamak, başlık, içerik; altta tam genişlik ana eylem.
- Uzun formlar alt sayfa değil tam ekran olur.

**Flutter:** `showModalBottomSheet(isScrollControlled: true, useSafeArea: true)`; tutamak ve köşeler `BottomSheetThemeData`'da.
