# AppIcon

İki mobil uygulamanın mağaza ve ana ekran ikonları ile web favicon'u; hepsi takvim kadranı amblemini taşır, zemin rengiyle ayrılır.

- **OMVILA İşletme**: koyu petrol zemin, amblemin ters sürümü. Çalışanların telefonunda müşteri uygulamasından hemen ayırt edilir.
- **OMVILA**: açık kum zemin, amblemin varsayılan sürümü. Müşteri uygulaması.
- **Favicon**: küçük boy amblem (mercan başlık, onay işareti). Web sitesi, rezervasyon sayfası ve panel.

Kurallar:
- İkon üzerine metin, rozet veya sektör simgesi eklenmez.
- Mağaza görsellerinde iki uygulama birlikte gösterilecekse işletme ikonu solda durur.
- Android bildirim ikonu için tek renk beyaz küçük amblem kullanılır.
