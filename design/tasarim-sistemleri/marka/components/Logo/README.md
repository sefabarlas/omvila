# Logo

Takvim kadranı amblemi ve OMVILA kelime markası; zemine ve alana göre doğru sürümü seçin.

## Ne zaman hangisi

| Alan | Dosya |
|---|---|
| Açık zemin (`zemin`, `zemin-yukseltilmis`, `zemin-ikincil`) | `omvila-logo-yatay.svg` |
| Koyu zemin (`zemin-marka`, koyu tema) | `omvila-logo-yatay-ters.svg` |
| Açılış sayfası, sunum, baskı | `omvila-logo-slogan.svg` / `-ters.svg` |
| Fotoğraf üstü, tek renk baskı | `omvila-logo-mono-petrol.svg` / `omvila-logo-mono-beyaz.svg` |
| Kare alan (avatar, profil) | `omvila-amblem.svg` / `omvila-amblem-ters.svg` |
| 48px altı, favicon | `omvila-amblem-kucuk.svg` |

## Kurallar

- Koruma alanı: her yanda takvim halkası deliğinin çapının üç katı.
- En küçük boy: yatay logo 96px genişlik; altında amblem, 48px altında küçük amblem.
- `<img>` ile, `alt="OMVILA"` verilerek kullanılır.
- Yapmayın: amblem ile yazının oranını değiştirmek, yazıyı başka fontla yazmak, gerdirmek, döndürmek, gölge veya degrade eklemek, başlığı mercan dışında bir renge boyamak, logoyu `vurgu` zemine koymak.
