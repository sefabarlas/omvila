# Uygulama

1024×1024 SVG kaynaklar. Köşeler önizleme içindir; mağazaya gönderirken köşesiz kare PNG dışa aktarın, maskeyi iOS ve Android uygular.

- `app-icon-isletme.svg`: **OMVILA İşletme** (salon uygulaması). Zemin petrol-900, amblemin ters sürümü (kum-50 gövde, mercan başlık).
- `app-icon-musteri.svg`: **OMVILA** (müşteri uygulaması). Zemin kum-100, amblemin varsayılan sürümü.
- `favicon.svg`: Web sitesi, rezervasyon sayfası ve panel sekmesi ikonu; küçük boy amblem. 16, 32 ve 48px PNG'ler bundan üretilir.
