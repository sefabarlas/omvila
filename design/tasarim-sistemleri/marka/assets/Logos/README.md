# Logolar

Takvim kadranı amblemi ve OMVILA kelime markası. Tümü dış hatlara çevrilmiş SVG'dir, font gerektirmez. Renkler dosyaya gömülüdür (`<img>` ile renk değiştirilemez). Takvim halkası delikleri gerçek boşluktur, zemini gösterir.

- `omvila-logo-yatay.svg`: Varsayılan logo. Gövde ve yazı petrol-900, başlık mercan-400, kadran beyaz, dolu çeyrek petrol-200. Açık zeminlerde.
- `omvila-logo-yatay-ters.svg`: Koyu zemin sürümü. Gövde ve yazı kum-50, kadran petrol-900, dolu çeyrek petrol-500. `zemin-marka` ve koyu temada.
- `omvila-logo-slogan.svg` / `omvila-logo-slogan-ters.svg`: "Her randevu tek yerde." sloganlı sürüm; açılış sayfası, sunum, baskı.
- `omvila-logo-mono-petrol.svg`: Tek renk petrol-900; tek renk baskı, kabartma, açık fotoğraf üstü.
- `omvila-logo-mono-beyaz.svg`: Tek renk beyaz; koyu fotoğraf üstü, `marka` dolgulu alanlar.
- `omvila-amblem.svg` / `omvila-amblem-ters.svg`: Amblem tek başına; avatar, sosyal medya profili.
- `omvila-amblem-kucuk.svg`: 48px altı için sadeleştirilmiş amblem (kadran yok; mercan başlık + beyaz onay).
