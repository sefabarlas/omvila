# packages/api-client-dart/: Dart API istemcisi (`omvila_api`)

`contracts/openapi.yaml`'dan `openapi-generator` (`dart-dio`, `json_serializable`, `enumUnknownDefaultCase=true`) ile üretilir.

## Kurallar
- Bu paketin içeriği üretilmiştir, **elle düzenlenmez.** Sözleşmeyi değiştirip `pnpm --filter @omvila/contracts generate:dart` çalıştırın; komut `dart pub get` ve `build_runner`'ı da çalıştırır (`.g.dart` dosyaları commit edilir). CI yeniden üretip fark arar.
- Elle tutulan yalnız şu dosyalar (`.openapi-generator-ignore`): `pubspec.yaml` (SDK ^3.8: üretilen JSON kodu null-aware-elements kullanır; `resolution: workspace`), `build.yaml` (`disallow_unrecognized_keys: false`: sunucuya eklenen yeni alan eski istemciyi bozmasın), `.gitignore`, `AGENTS.md`.
- Üretici ayarı `contracts/openapitools.json`'da. Üretici, sözleşmenin `contracts/scripts/dart-spec.mjs` ile hazırlanan geçici kopyasını okur: üreticinin iki hatası nedeniyle boolean `const` ve satır içi enum `default` değerleri yalnız bu kopyadan kaldırılır (kuralı sunucu uygular).
- Özel şablonlar `contracts/templates/dart-dio/` (üreticinin gömülü şablonlarını aynı yolla geçersiz kılar; T-110): `format: date` alanları ve sorgu parametreleri `DateTime` tipli kalır ama "yyyy-MM-dd" yazılır (`lib/src/date_only.dart`: `DateOnlyConverter`, `formatDateOnly`); dizi sorgu parametreleri sözleşmedeki biçimle (`explode: false` → `ListFormat.csv`, ör. `staffIds=a,b`) gider. `date-time` alanları değişmez (`toIso8601String()`, UTC). Davranışı `packages/omvila_ui/test/api_serialization_test.dart` doğrular. Uygulamalar `format: date` alanına düz `DateTime` verir (`parseLocalDate`, omvila_ui); ek sarmalayıcı gerekmez. İstek gövdesinden ulaşılan şemalarda isteğe bağlı ve null alabilen alan (`type: [x, 'null']`) `includeIfNull: true` ile **her zaman** yazılır (verilmezse `null` = boşalt; işaret `contracts/scripts/dart-spec.mjs` → `x-send-null`, T-113); null alamayan isteğe bağlı alan verilmezse gönderilmez (PATCH anlamı). PATCH şemalarında (ör. `MeProfileUpdate`, `BrandUpdate`) çağıran null alabilen alanların güncel değerini her istekte verir.
- Paket Dart workspace üyesidir (kök `pubspec.yaml`); kendi `pubspec.lock`'u yoktur, sürümler kökteki `pubspec.lock`'ta sabittir ki `build_runner` çıktısı CI'da birebir aynı olsun. Üretilmiş kod Melos `format:check` ve `analyze` betiklerinin dışındadır (derlenmesini `contracts.yml` denetler).
- Bilinmeyen enum değerleri `unknownDefaultOpenApi` olarak çözülür; uygulamalar bunu genel durum olarak gösterir.
- Kimlik doğrulama, yenileme, `Idempotency-Key`, `If-Match` ve hata eşleme bu pakette değil, `packages/omvila_ui` içindeki `api/` katmanında (Dio interceptor'ları) yazılır.
